Standing waves

A wave on a string of finite length reflects off both ends and runs into itself. Only certain frequencies survive that, and this page works out which — the same counting that gives an instrument its notes.

A wave that goes nowhere

Section 2.4 showed a pulse reaching an end comes back. On a string fixed at both ends that happens forever, so at any moment the string carries waves going both ways at once. Section 1.2 says we may simply add them.

Look at what that says. The $x$ and the $t$ have come apart into separate factors. The shape along the string, $\cos kx$, never changes; only its overall size breathes in and out with $\cos\omega t$. Nothing travels. Points where $\cos kx = 0$ never move at all — the nodes — and points where $\abs{\cos kx} = 1$ swing hardest — the antinodes.

Two equal waves running opposite ways add to a fixed shape that only changes size, which is why nothing appears to travel.

A string held at both ends

Section 2.4 showed a fixed end has $R = -1$: the reflection comes back inverted. Putting that sign into the sum changes which combination survives.

So only a discrete set of frequencies fits, all whole-number multiples of the lowest one, $f_1 = v/2L$. That is the fundamental, and the rest are its harmonics. The reason a plucked string sounds like a note rather than a noise is that this list is all it can do.

Read $\lambda_n = 2L/n$ backwards and it says something simpler: the string holds exactly $n$ half-wavelengths. A half wavelength is the distance between neighbouring zeros of a sine, so a string with both ends held must contain a whole number of them.

Worked example

A guitar string, $L = 0.65\unit{m}$, with $\Ten = 80\unit{N}$ and $\mu = 4.4\unit{g/m}$.

$v = \sqrt{80/0.0044} = 134.8\unit{m/s}$.

$\lambda_1 = 2L = 1.30\unit{m}$ and $f_1 = 134.8/1.30 = 103.7\unit{Hz}$ — near a low G♯. The next two are $207\unit{Hz}$ and $311\unit{Hz}$.

Fretting the string halves $L$, which doubles every frequency: one octave up, which is why the twelfth fret sits at the midpoint.

A string held at both ends must contain a whole number of half wavelengths, so $\lambda_n = 2L/n$ and $f_n = nv/2L$.

One end free

Now let the far end be a ring sliding on a frictionless pole. Section 2.4 called this a free end and found $R = +1$. The condition there is different: the end is free to move, so it is not the displacement that must vanish but the slope — a non-zero slope would mean the string pulling sideways on a ring that has nothing to pull against.

Two consequences. The fundamental is $v/4L$, an octave below the fixed-fixed string of the same length. And the frequencies go $1, 3, 5, \ldots$ times that: the even harmonics are missing entirely. A clarinet, which is a tube closed at the mouthpiece and open at the bell, behaves this way, and it is why a clarinet sounds different from a flute of the same length.

Worked example

$L = 0.5\unit{m}$ with one end free.

$\lambda_1 = 4L = 2.0\unit{m}$, $\lambda_2 = 4L/3 = 0.667\unit{m}$, $\lambda_3 = 4L/5 = 0.400\unit{m}$.

With the same string held at both ends the wavelengths would have been $1.0$, $0.5$ and $0.333\unit{m}$ — a different list entirely.

A free end needs zero slope rather than zero displacement, so the string holds an odd number of quarter wavelengths and the even harmonics vanish.

Nodes, antinodes, and a look back at 1.3

For the $n$th mode of a fixed-fixed string the shape is $\sin(n\pi x/L)$. Its zeros are at $x = 0, L/n, 2L/n, \ldots, L$ — that is $n+1$ nodes counting both ends, spaced $\lambda_n/2$ apart. The antinodes sit halfway between them.

It is worth noticing what these mode shapes are. They are exactly the functions $\sin(n\pi x/L)$ whose mutual perpendicularity section 1.3 proved, and whose use as a basis section 1.4 built the Fourier series on. That is not a coincidence: plucking a string somewhere and letting go is starting it in a shape that is not a single mode, and what happens next is that the shape is decomposed into modes — a Fourier series — each of which then oscillates at its own frequency. The same decomposition, and for the same reason, as splitting a coupled-oscillator motion into normal modes in section 2.2.

The mode shapes of a string are the same orthogonal sines that Fourier series are built from, so a plucked string is a Fourier decomposition in action.

Check yourself
  1. Where are the nodes of the third harmonic on a string of length $L$ held at both ends?
    Answer
    $\sin(3\pi x/L) = 0$ at $x = 0,\, L/3,\, 2L/3,\, L$: four nodes, two of them the ends.
  2. Why does the fixed-free string have no even harmonics?
    Answer
    The condition is $\cos kL = 0$, which happens only at odd multiples of $\pi/2$. An even multiple of the fundamental would need $\cos kL = \pm1$, which is a maximum of the slope, not a zero.
  3. The tension is doubled. What happens to $f_1$?
    Answer
    $v = \sqrt{\Ten/\mu}$ grows by $\sqrt2$, and $f_1 = v/2L$, so the frequency rises by $\sqrt 2 = 1.414$ — about a perfect fifth, which is why tuning is done with the tension.
  4. A string of length $0.8\unit{m}$, held at both ends, has $f_1 = 200\unit{Hz}$. What is the wave speed?
    Answer
    $\lambda_1 = 2L = 1.6\unit{m}$, so $v = \lambda_1 f_1 = 320\unit{m/s}$.
  5. Where are the antinodes for $n = 2$ on a fixed-fixed string?
    Answer
    The shape is $\sin(2\pi x/L)$, largest where its argument is $\pi/2$ and $3\pi/2$: at $x = L/4$ and $x = 3L/4$, with a node between them at the midpoint.
